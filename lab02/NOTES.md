# Git: рабочая папка, индекс и коммит

- Рабочая папка — это папка на компьютере, где лежат наши файлы.
- Индекс — это промежуточная зона, куда мы добавляем файлы перед сохранением.
- Коммит — это сохранение (снимок) в истории Git.
## Git и GitHub
- Git — работает на компьютере.
- GitHub — это сайт в интернете, где хранятся репозитории.

### git diff и git diff --staged
- git diff — показывает, что изменилось в рабочей папке, но еще не добавлено в индекс.
- git diff --staged — показывает, что уже добавлено в индекс и попадет в следующий коммит.
## Использованные команды
- git status — показывает состояние файлов (изменены, в индексе, закоммичены).
- git diff — показывает разницу между рабочей папкой и индексом.
- git diff --staged — показывает разницу между индексом и последним коммитом.
