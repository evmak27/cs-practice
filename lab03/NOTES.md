## Сравнение версий и поиск изменений
- git diff: показывает разницу между рабочей папкой и индексом (или между коммитами).
- git show: показывает подробную информацию о конкретном коммите.
- git log -S"def": ищет коммиты, в которых появлялось или исчезало слово "def".
- git blame: показывает, какой коммит и автор написали каждую строчку в файле.
## Восстановление файла
- git restore lab03/calc.py: возвращает файл к состоянию последнего коммита (отменяет текущие правки).
- git restore --source=HEAD~2 lab03/calc.py: достает версию файла из конкретного старого коммита (на 2 коммита назад).
